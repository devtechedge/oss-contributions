paraphrased; where a sentence is quoted on its own it is a complete sentence in the linked
comment.

The "Kind words from maintainers" section in the README is a curated subset of this file. Add a
quote here first, then splice the same line into the README between

outside the generated merged-table markers, so a ledger sync cannot overwrite the section.

- Merged pull requests only. Never quote an open PR.
